# lemanida-preuves

Canal public des empreintes SHA-256 de la finale du concours Lémanida (19 novembre 2026, heure de Zurich).

Les empreintes sont publiées dans une seule issue verrouillée : [« Finale du 19-11-2026 — empreintes publiées »](https://github.com/wecode-swiss-bruno/lemanida-preuves/issues/1). L'heure qui fait foi est l'heure de création de chaque commentaire, tenue par GitHub.

Ce dépôt ne contient aucun fichier de la finale ni aucune donnée personnelle. Après le tirage, les fichiers publics (`engagement.json`, `gel.json`, `tirage.json`, et le cas échéant `remplacement-<n>.json`) sont mis en ligne sur https://lemanida.ch/finale-2026/preuve/ : chacun peut recalculer leur empreinte (`shasum -a 256 <fichier>`) et la comparer à celle publiée dans l'issue.
